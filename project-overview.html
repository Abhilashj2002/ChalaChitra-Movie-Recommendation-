ChalaChitra

Frontend and Backend

Frontend

  • Location: project root
  • Framework: React with Vite
  • Default URL: http://localhost:3001
npm install
npm run dev

Backend

  • Location: server folder
  • Runtime: Node.js + Express
  • Default URL: http://localhost:3002
cd server
npm install
npm run dev

API Keys and TMDB

Do not commit real API keys. Keep real keys in .env.local, local admin settings, or deployment secrets only.

  1. Copy .env.example to .env.local.
  2. Add your own values for VITE_TMDB_API_KEY, VITE_GEMINI_API_KEY, and optional VITE_OMDB_API_KEY.
  3. Restart the frontend after editing .env.local.
  4. Admins may also add the TMDB key in the Admin Dashboard for local app settings.
VITE_GEMINI_API_KEY=your_real_gemini_api_key
VITE_TMDB_API_KEY=your_real_tmdb_api_key
VITE_TMDB_BASE_URL=https://api.themoviedb.org/3
VITE_OMDB_API_KEY=your_real_omdb_api_key
